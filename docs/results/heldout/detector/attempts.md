# Grasp attempts (Block 4 labels)

An attempt is a close command within 15 cm of a goal object while none is held, running until the fingers reopen. Success: a hold on a goal object begins before then and does not end in a slip (the classifier's rule). Aborted: the fingers reopen before closing past 7 cm. Harness `cf6b134`.
